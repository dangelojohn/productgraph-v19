Critical — Unresolved
🚨 These rules have not been formally decided. Without this document, AI coding agents will implement conflicting behavior for the most operationally dangerous scenarios in the system. Decide before writing any Release or MO-linked code.
📋 Scenario 1: Revision Released — Open Manufacturing Order Exists
New Revision B is released while 4 MOs reference the existing mrp.bom (Rev A). What happens to those open MOs?
FREEZE
Recommended: Existing open MOs remain pinned to mrp.bom Rev A. The MO is not automatically updated. Manufacturing runs to completion against the original BOM they were created with.
WARN
All stakeholders (Manufacturing Engineer, Production Planner) receive a notification: "New BOM revision available — existing MOs continue on Rev A."
ALLOW
New MOs created after release date automatically reference the new mrp.bom (Rev B).
🛒 Scenario 2: Revision Changes — Open Purchase Order Exists
A purchased component revision changes from A→B while an open PO references Rev A. What behavior is required?
WARN
Recommended: Procurement receives a warning notification. The PO is NOT automatically updated — procurement manually decides whether to amend the PO or allow receipt against Rev A stock.
BLOCK
Alternative: Block new PO creation for Rev A after Rev B release. Force procurement to explicitly choose Rev B on any new purchase.
📦 Scenario 3: Revision Changes — Existing Inventory in Stock
100 units of Part Rev A sit in inventory. Rev B is released. Can Rev A stock be consumed in production?
ALLOW
Recommended: Rev A stock can be consumed unless the ECO or release document explicitly marks Rev A as "Do Not Use." Engineering must proactively flag incompatible revisions.
WARN
If consumed, the production record is annotated: "Built with Rev A stock — Rev B BOM in effect." Traceability preserved.
🔄 Scenario 4: Alternate Parts — Can They Auto-Replace?
HINGE-A alternate group exists. Primary hinge is out of stock. Can the system auto-substitute an approved alternate?
BLOCK
Default: Auto-substitution is blocked. A human (Manufacturing Engineer or Production Planner) must explicitly approve any alternate part use on a per-MO basis.
ALLOW (Future)
Phase 2: Approved alternates in an Approved Vendor/Part List may be auto-substituted if an AVL flag permits it. Requires explicit AVL governance first.
