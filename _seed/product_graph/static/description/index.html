ProductGraph – Engineering Lifecycle & PLM

Odoo 19 CE Manufacturing PLM Open Source LGPL-3 Co-developed with Claude AI

ProductGraph gives engineering teams a governed, auditable path from design intent to manufacturing. Items, revisions, and Bills of Materials live under strict lifecycle rules, while Odoo's mrp.bom is created in exactly one place — guaranteeing that nothing reaches the shop floor without a formal approval.

Key Features

📦 Item Registry

A single source of truth for every engineering item, completely separate from Odoo's product catalogue until formally released.

🔄 Revision Control

Full draft → in_review → approved → released → obsolete lifecycle. Released revisions are immutable — changes require an ECR.

⚡ Controlled BOM Release

mrp.bom records are created in exactly one code path: PgRelease.action_execute_release(). No BOM reaches Odoo without a Release Manager sign-off.

📝 Change Request (ECR) Workflow

Formal ECO/ECR process with impact analysis, approver routing, rejection capture, and automatic revision creation on approval.

🏭 Manufacturing Collision Detection

Automatic detection of open Manufacturing Orders before obsolescence is permitted. Prevents accidental production disruption.

🔒 Full Audit Log

Tamper-evident, append-only log of every state change and release event. Write and delete are blocked at ORM level.

🌐 REST API

JSON endpoints for CAD tool integration, ERP bridges, and automated testing. Health, items, revisions, and BOM endpoints included.

🤖 Digital Twin Stubs

Reserved schema path pg.item → pg.asset → IoT device for Phase 2 telemetry — no migration required later.

Architecture Principles

Governance guarantee: ProductGraph owns pg.* — Odoo owns mrp.*. The only way a Bill of Materials enters Odoo manufacturing is through the formally gated Release process. No workarounds, no exceptions.
  • Released items and revisions are immutable at ORM level — not just UI-locked.
  • All state transitions are guarded by explicit _check_transition_allowed() with logged rejection reasons.
  • Audit log records raise UserError on any write() or unlink() attempt.
  • BOM creation is a single, audited, role-gated operation.

Installation

  1. Download and extract to your Odoo addons path.
  2. Restart the Odoo server: ./odoo-bin -c odoo.conf
  3. Update the module list in Settings → Technical → Update Module List.
  4. Install ProductGraph from Apps.
  5. Assign users to ProductGraph groups under Settings → Users.

Compatibility

Odoo 19.0 Community Edition. Depends on: base, mail, product, mrp, stock, web.
